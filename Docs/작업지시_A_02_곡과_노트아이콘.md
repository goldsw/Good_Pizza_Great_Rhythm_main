# 작업지시 A-02 — 노트 아이콘

담당: A (데이터와 에디터)
전제: C-02가 스프라이트를 `Assets/GPGR/Art/Notes/`에 넣어 둔 뒤 시작한다. 그 경로가 없으면 아이콘을 비운 채로 보고하고, 채보의 다른 값은 건드리지 않는다.

상시 규칙은 `지침_A_데이터와_에디터.md`, 아이콘이 어디에 있는지는 `Docs/Unity_구조.md` §2를 본다. 씬, 프리팹, `Assets/GPGR/Art/`는 C 소유다. 그림을 복사하거나 `.meta`를 고치지 않는다.

**곡은 넣지 않는다.** `Sound_src`의 BGM은 쓰지 않는다. `DemoChart.clip`은 비워 둔다. `Assets/GPGR/Audio/`를 만들지 않는다. 클락은 클립이 없으면 BPM으로 돈다.

---

## 0. 구조에서 내가 꽂는 것

`NoteRow`에 아이콘이 있다. 뷰는 `NoteRow.icon`을 읽어 그린다.

| 프로젝트 파일 | 꽂는 곳 |
|---|---|
| `Assets/GPGR/Art/Notes/Dough.png` | 프리셋 `반죽` |
| `Assets/GPGR/Art/Notes/Sauce.png` | 프리셋 `토마토 소스` |
| `Assets/GPGR/Art/Notes/Cheese.png` | 프리셋 `치즈 뿌리기` |
| `Assets/GPGR/Art/Notes/Pepperoni.png` | 프리셋 `페퍼로니` |

오븐 페이즈는 아이콘을 비운다. 오븐 재료 그림이 없다. 완성 페이즈는 행이 없다.

배경, 원판 아래 검은 길, 스폰 이펙트, 타격 이펙트는 C다. `Docs/작업지시_C_03_배경과_파티클.md`를 본다. 나는 손대지 않는다.

## 1. 아이콘

**Chart Editor에서 행마다 아이콘을 지정하지 않는다.** 재료 그림은 네 장으로 확정돼 있다. 이 대응은 `NotePresetLibrary`에 둔다. 프리셋으로 행을 만들면 `NoteRow.icon`에 그 스프라이트가 이미 들어 있어야 한다.

이미 만들어진 `DemoChart`도 에디터에서 한 줄씩 고치지 않는다. 프리셋 이름과 같은 페이즈의 행에, 코드로 한 번에 넣는다. 페이즈 이름이 `치즈`여도 행 이름이 `치즈 뿌리기`면 치즈 그림을 쓴다.

런타임은 저장된 `icon`만 읽는다. `if (phaseName == "치즈")` 같은 분기를 `GPGR.View`나 `GPGR.Runtime`에 넣지 않는다.

BPM, 오프셋, 스폰 각, 히트 각, 경로 키, 히트 박, 꼬리, 색, 재생 방식, `clip`은 바꾸지 않는다. 지금 데모는 사람이 고친 경로가 들어 있다.

**`GPGR/Create Demo Chart Asset`을 실행하지 않는다.** 그 메뉴는 채보를 다시 만들고 지금 경로가 사라진다.

색은 그대로 둔다. 아이콘 렌더러가 이 색을 곱하고, 트레일도 이 색을 쓴다. 그림이 탁해 보이면 흰색으로 바꾸지 말고 보고한다.

경로는 이름 검색으로 프로젝트 전체를 뒤지지 않는다.

```
Assets/GPGR/Art/Notes/Dough.png
Assets/GPGR/Art/Notes/Sauce.png
Assets/GPGR/Art/Notes/Cheese.png
Assets/GPGR/Art/Notes/Pepperoni.png
```

이 네 경로는 프리셋 정의 옆에 적는다. Chart Editor의 아이콘 칸은 결과만 보여 주는 자리다. 거기 넣으려고 열지 않는다.

---

## 2. 확인

1. `DemoChart.clip`이 비어 있다
2. 반죽·소스·치즈·페퍼로니 행의 `icon`이 비어 있지 않다. 치즈 행이 여러 개면 전부 같다
3. 오븐 행의 `icon`은 `{fileID: 0}`이다
4. 경로의 `angleDeg`와 `hitBeats`가 이 작업을 하기 전과 같다
5. `ChartLayout.Validate`에 새 오류가 없다. 아이콘이 비어 있는 것은 검증 오류가 아니다

플레이 확인은 C가 한다. 나는 `editor_play`를 켜지 않는다.

---

## 3. 끝나고 보고할 것

1. 페이즈별 아이콘이 들어간 행 수
2. 오븐 아이콘은 비웠다는 것
3. 경로, BPM, 클립을 안 바꿨다는 것
4. C의 스프라이트 경로가 없어서 못 넣은 것이 있는지
