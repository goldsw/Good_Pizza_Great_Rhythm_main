# 작업지시 C-09 — 오븐 테마를 더 어둡게

담당: C (뷰와 연출)

A와 B는 하지 않는다. 오븐인지는 페이즈 이름이 아니라 `backdrop == Dark`로 이미 갈린다. 고칠 곳은 `PhaseThemeView`와 어두운 배경의 색뿐이다.

---

## 1. 지금

오븐 페이즈에서 밝은 주방 위로 `BgDark`가 페이드인된다. 그 스프라이트의 색은 `(1, 1, 1)`이라 그림 밝기 그대로다. 노트, 레일, 피자, HUD는 이 전환에 포함되지 않는다. 그것도 그대로 둔다.

---

## 2. 더 어둡게

어두운 배경이 완전히 나타난 뒤의 색을 흰색보다 낮춘다. 인스펙터 필드로 둔다. 코드 안에 상수로 박지 않는다.

잠정 `ovenTint`는 `(0.55, 0.48, 0.42)`다. 알파가 0에서 1로 올라가는 동안 이 색으로 간다. 밝은 페이즈로 돌아올 때는 어두운 장의 알파만 내리고, 밝은 주방 색은 흰색을 유지한다.

화면이 거의 검게 닫히면 잠정값보다 올린다. 주방이 그대로 환하면 잠정값보다 내린다. 기준은 화덕이 있는 배경이 한 단계 가라앉고, 원판 위의 재료는 그대로 읽히는 것이다.

---

## 3. 확인

`editor_play`로 오븐 페이즈와 완성 페이즈를 본다.

| 볼 것 | 맞는 모습 |
|---|---|
| 오븐 | 배경이 지금보다 어둡다 |
| 재료 | 아이콘, 레일, 히트 마커의 밝기는 오븐 전후가 같다 |
| 완성 | 배경이 다시 밝은 주방으로 돌아온다 |
