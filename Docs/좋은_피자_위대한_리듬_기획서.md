# 좋은 피자, 위대한 리듬

**버전:** 최종사안 + 구현 보충 + 노트 최종 기획  
**원본:** 노션 기획서 `좋은 피자, 위대한 리듬 <최종사안>`  
**팀:** 게임 프로젝트 입문 3팀 · 좋팀위팀 (좋은 팀, 위대한 팀)

이 문서는 노션 최종사안을 기준으로, 구현 범위와 노트 최종 기획을 보충한 버전이다.  
손님 대사·경영·풀게임 루프는 의도적으로 빼거나 영상 쪽으로 넘긴다.

---

## 1. 한 줄 요약

요리 경영 시뮬레이션을 리듬게임으로 비튼다.  
피자 제작의 각 과정을 원판이 도는 채보로 바꾸고, **테마(페이즈)가 바뀔 때마다** 주방 연출이 바뀐다.

최종 산출물은 **플레이 가능한 풀게임이 아니라 트레일러용 Unity 연출 씬**이다.  
플레이어블 히트와 테마 전환만 엔진에서 만들고, 손님 말풍선·로고·컷 연결은 영상 편집이 맡는다.

### 제작 과정 (원안)

Unity로 인/아웃 게임 씬과 노트 시스템을 구현한다. 노트 시스템은 Optional로 적혀 있었으나, **트레일러용으로 노트·테마·오븐 연출은 구현한다.**  
최종 산물은 편집 툴로 붙인다.

## 4. 구현 범위

### 한다 (Unity)

- 원판 반시계 회전 노트, 하단 히트 라인, 노트 뒤 트레일
- 롱노트는 **머리가 히트 라인에 온 뒤 꼬리가 원호를 따라간다**
- 스페이스(지정 키) 히트 입력은 구현한다. 다만 **트레일러 촬영은 직접 치지 않고 자동 재생을 쓴다. 판정은 Good과 Perfect를 섞어 자동으로 낸다**
- 페이즈 = 테마 전환. 한 테마 노트가 **전부 끝난 다음**에 다음 테마 노트가 나온다. 테마끼리 노트가 겹치지 않는다
- 재료별 확정 채보: 롱노트(반죽, 오븐), 단일 노트(소스 1회, 치즈 2회, 페퍼로니 1회·빠른 접근)
- 페퍼로니 → 오븐 → 완성 연출
  - 피자가 오븐에 들어간다. **원판·히트 라인은 그대로** 두고, 어두운 배경에서도 노트 치는 과정은 같다
  - 오븐 테마: 어두운 배경 + **꾹 눌러 굽는 롱노트**
  - 완성 테마: 다시 밝은 배경, 피자가 나온다
- 판정 Perfect / Good / Bad / MISS 윈도우는 두되, **트레일러는 Good과 Perfect를 섞어 자동 재생**한다
- 정확도 100% 시작, Perfect는 감점 없음, Good만 소량 감점. Bad/Miss는 트레일러에서 안 쓴다
- Suno BPM에 맞춘 프리셋 채보 툴 (`GPGR/Chart Editor`)

### 안 한다

- 손님 말풍선, 손님 대사, 주문 UI → **영상 편집**
- 피자에 소스·치즈·토핑이 뿌려지는 과정, 채보 치는 타격 이펙트 → **영상 편집**
- 경영(시설, 패시브, 돈으로 업그레이드)
- 손님 1명 = 1스테이지라는 메타포의 메뉴/스테이지 선택 화면
- 안드로이드 전용 UX. 입력만 나중에 켜기 쉽게 둔다
- 사람이 직접 쳐서 찍는 테이크. Miss가 나게 두지 않는다

## 5. 메인 루프 (플레이 환상)

원안 루프는 아래와 같다. Unity는 **굵은 부분만** 돌린다.

1. 손님이 들어온다 → 영상
2. “**(곡 이름) 피자를 주세요**” → 영상. 그 피자에 맞는 노래를 튼다는 설정
3. **주문이 재료 페이즈로 쪼개지고, 원판 채보가 돈다**
4. **히트에 맞춰 Good과 Perfect가 섞여 자동으로 뜬다**
5. **페퍼로니가 끝나면 오븐에 넣고 롱노트로 굽고, 완성된 피자가 나온다**
6. 만족한 손님 / 클리어 카드 → 영상
7. 경영 화면 → **안 만든다.** 원안도 “있는 정도만 보여 주고 넘어갈 것”

손님 1명 = 1스테이지 = 1곡.  
스테이지 선택·말풍선·손님 연기는 구현하지 않는다.

## 6. 리듬 플레이

### 원판

- 재료(노트)는 조리 순서대로 **피자 기준 왼쪽**에 스폰된다
- **반시계**로 돈다
- **가운데 하단**에 맞물렸을 때 스페이스(지정 키)를 누른다
- 기본 이동량 90° (왼쪽 → 하단). 채보 에셋에서 각도·접근 박자를 바꿀 수 있다
- 접근 박자 기본값: 2박
- 한 테마의 노트가 원판에 남아 있는 동안 다음 테마 노트는 나오지 않는다

### 롱노트 모양

반죽·오븐 롱노트는 **머리 + 꼬리**다.

- 머리가 가운데 하단에 맞물릴 때 누르기 시작한다
- 꼬리는 원판 **원호를 따라** 머리가 지나온 길을 채운다. 꼬리 길이는 박으로 하나만 정하고, 덮는 원호 길이는 거기서 나온다
- 판정은 **시작(머리)만** 본다. 끝 타이밍은 보지 않는다
- 트레일러에서는 머리 타이밍에 Good과 Perfect가 섞여 자동으로 난다

### 노트 트레일

노트(채보) 뒤에 지나온 경로를 따라가는 **트레일**을 붙인다.

- 원판을 따라 왼쪽에서 하단으로 이동하는 동안 항상 켜 둔다
- 치즈가 왼쪽으로 튕겼다가 돌아올 때도 트레일은 노트를 따라간다
- 히트하거나 놓치면 노트가 사라지면서 트레일도 같이 사라진다
- 재료마다 노트 색이 다르고, 트레일은 그 노트 색을 그대로 쓴다

길이·두께·페이드 시간은 아트 보고 정한다.

### 입력

| 장치 | 이번 범위 | 비고 |
| --- | --- | --- |
| 키보드 Space / Enter | 한다 | 메인 입력. 촬영은 자동 재생을 쓴다 |
| 마우스 클릭 | 한다 | 미리보기·에디터 확인 |
| 터치 | 구조만 | 같은 “히트” 이벤트 |

### 채보 종류 (최종)

채보 종류는 두 가지다. **롱노트**는 키를 누르고 있는 구간, **단일 노트**는 히트 라인에서 치는 횟수가 정해져 있다.

| 재료(채보) 이름 | 채보 종류 | 타격 횟수 | 타격 상세 |
| --- | --- | --- | --- |
| 반죽 | 롱노트 | 1 (머리만 판정, 이후 꾹 유지) | 피자의 가장 기초적인 재료, 도우. 채보를 꾹 눌러 돌린 도우를 만든다. |
| 토마토 소스 | 단일 노트 | 1 | 셰프의 엄청난 소스로 토마토 소스를 흩뿌린다. 한 채보당 한 번 누르면 된다. |
| 치즈 뿌리기 | 단일 노트 | 2 | 하단에서 첫 타 → **왼쪽으로 튕김** → **다시 하단에 왔을 때** 두 번째 타. |
| 페퍼로니 | 단일 노트 | 1 | 다른 채보보다 **빠르게 다가온다.** 한 번 친다. |
| 오븐 | 롱노트 | 1 (머리만 판정, 이후 꾹 유지) | 채보를 꾹 눌러 피자를 굽는다. |

공통 규칙:

- 반죽·오븐은 롱노트. 꼬리가 원호를 따라가고, **판정은 머리(시작)만** 본다.
- 토마토 소스·페퍼로니는 히트 라인에서 **한 번**.
- 치즈는 같은 채보를 **두 번** 친다. 둘 다 치는 위치는 **가운데 하단 히트 라인**이다.
  1. 왼쪽에서 내려와 하단에서 첫 타
  2. **스폰 쪽(왼쪽)으로 튕긴다**
  3. **다시 하단에 돌아오면** 두 번째 타
  첫 타를 놓치면 튕기지 않고 **노트가 바로 사라진다.** 트레일러 자동 재생에서는 그 경우가 없다.
- 페퍼로니만 접근 속도가 다르다. 같은 히트 라인이라도 더 빨리 도착한다.
- 피자에 재료가 붙는 연출, 칠 때 이펙트는 Unity가 하지 않는다. **영상 편집.**

예전 초안의 Tap / DoubleTap / Hold / Relocate 이름은 쓰지 않는다. 위 다섯 재료가 곧 노트 종류다.

### 판정 윈도우

히트 시각과 노트 시각의 절대 오차. 트레일러는 사람이 치지 않고, 각 히트마다 **Good과 Perfect를 섞어** 자동으로 낸다. Bad와 Miss는 쓰지 않는다.

| 판정 | 윈도우 | 트레일러 |
| --- | --- | --- |
| Perfect | ≤ 50ms | 쓴다 |
| Good | ≤ 100ms | 쓴다 |
| Bad | ≤ 160ms | 안 쓴다 |
| Miss | 그 밖 | 안 쓴다 |

윈도우가 서로 겹치므로 위에서부터 먼저 맞는 줄을 쓴다. 오차 30ms는 Perfect다.

빈 입력은 감점하지 않는다. 치즈 첫 타를 놓치면 노트는 바로 사라지지만, 트레일러 자동 재생에서는 그 경우가 나오지 않는다.

### 정확도

원안의 “타이밍이 좋을수록 피자 가격 증가”를, 트레일러에 맞게 **정확도 게이지**로 바꾼다.

- 시작 100%
- Perfect: 감점 없음
- Good: −2%p
- Bad / Miss: 수치는 두되 트레일러에서는 발생하지 않는다
- 0% ~ 100%로 클램프

가격·돈 정산은 없다.

## 7. 테마 = 페이즈

페이즈가 갈린다는 말은 **테마가 바뀐다**는 뜻이다.  
반죽 → 토마토 소스로 넘어가면 주방 테마가 바뀐다. 페이즈마다 원판 틴트 색을 하나 둘 수 있으나, 원안 기획에는 원판 색 변경이 없어서 데모는 전부 비워 둔다.

### 전환 규칙

한 테마의 노트가 **원판에서 모두 끝난 다음**에야 다음 테마 노트가 나온다. 테마끼리 노트가 겹치지 않는다. 끝난 뒤 쉬는 박자를 일부러 넣지는 않는다.

1. 지금 테마 노트가 전부 판정·소멸한다
2. 바로 다음 테마로 바꾸고, 그 테마 노트가 왼쪽에서 내려오기 시작한다
3. 피자에 재료가 뿌려지는 컷은 Unity가 만들지 않는다. **영상 편집**
4. 완성만 노트가 없다. 오븐 롱노트가 끝나면 바로 피자가 나오는 연출로 간다

### 테마 목록

테마 순서는 확정 재료와 같다. 치즈는 건너뛰지 않는다.

| 테마 | 채보 | 연출 |
| --- | --- | --- |
| 반죽 | 롱노트 | 밝은 주방, 도우. 꾹 눌러 도우를 돌린다 |
| 토마토 소스 | 단일 1회 | 소스 테마. 피자에 뿌려지는 컷은 편집 |
| 치즈 뿌리기 | 단일 2회 + 좌측 튕김 후 하단에서 재타 | 치즈 테마. 뿌려지는 컷은 편집 |
| 페퍼로니 | 단일 1회, 빠른 접근 | 페퍼로니 테마. 올리는 컷은 편집 |
| 오븐 | 롱노트 | 피자가 오븐에 들어감. **원판·히트 라인은 유지.** 어두운 배경에서도 치는 과정은 같음 |
| 완성 | 없음 | **밝은 배경**으로 복귀, 피자가 나옴 |

배경은 **밝은 주방 / 어두운 오븐** 두 장이다. 그래서 반죽·소스·치즈·페퍼로니는 배경이 같다. 이 네 테마의 구분은 **노트 아이콘과 색**이 하고, 배경이 실제로 바뀌는 곳은 오븐과 완성뿐이다.

### 페퍼로니 → 오븐 → 완성 (필수 연출)

1. 페퍼로니 노트가 끝난 다음, 쉬는 박자 없이 오븐 롱노트가 나온다
2. 피자가 오븐 쪽으로 들어가며 작아진다
3. 배경이 어두워진다. **원판과 히트 라인은 그대로**다. 노트는 같은 하단에서 친다
4. **오븐 롱노트** 머리가 히트 라인에 오면 굽기 시작, 꼬리는 원호를 따른다
5. 피자가 다시 나오고 배경이 밝아진다 (완성 테마)

여기까지가 Unity 연출의 상한이다.

데모 루프:

`반죽 → 토마토 소스 → 치즈 뿌리기 → 페퍼로니 → 오븐 → 완성`

## 8. 채보 툴

곡은 Suno로 뽑고, BPM에 맞춰 프리셋으로 짠다.

- 메뉴: `GPGR/Chart Editor`, `GPGR/Create Demo Chart Asset`
- 에셋: `Song Chart` (BPM, 오프셋, 기본 접근 박자, 기본 스폰·히트 각, 판정 창, 정확도 감점, 재생 방식, 페이즈 배열, 오디오 클립)
- 프리셋 예: 반죽 롱노트, 소스 1회, 치즈 2회(좌측 튕김 후 하단 재타), 페퍼로니 빠른 1회, 오븐 롱노트

채보 한 줄은 **페이즈 시작 기준 박자**다. 곡 전체 타임라인은 디렉터가 이어 붙인다.

## 9. 트레일러 영상 흐름 (약 1분)

원안 흐름도. Unity가 찍을 컷과 편집이 붙일 컷을 나눈다.

| # | 구간 | 설정 | Unity | 편집 / 아트 |
| --- | --- | --- | --- | --- |
| 1 | 인트로 | 팀 로고 페이드, 검은 화면 | 선택 | 팀 로고 |
| 1-2 | 인트로 | 여자가 노래하는 장면. 게임 BGM과 동일 곡 | 안 함 | 가게 외관, 여성 애니메이션 |
| 2 | 인트로 → 메인 | 가게 밖 사람들, 주인공이 가게로 들어감 | 안 함 | 가게 외관, 여성 애니메이션 |
| 3~4 | 메인 메뉴 | 스테이지(손님) 선택처럼 보이게 | 안 함 | 메인 메뉴 배경, UI, 손님 |
| 4-1 | 인게임 | 리듬에 맞춰 피자를 완성하라. 재료 노트가 반시계 | **한다** | 인게임 배경, UI, 손님 오버레이 |
| 5 | 인게임 클리어 | 만족한 손님, 승리 오버레이 | 정확도·완성 피자 | 주방장 초상화, 손님, 클리어 카드 |
| 6 | 경영 한 컷 | 시설이 있는 가게 | **안 함** | 가게 시설 일러스트 |
| 7 | 아웃트로 | 게임 로고, 가게 외관 | 선택 | 게임 로고 |

나레이션 후보 (편집):

- “리듬에 맞춰 피자를 완성하라!”
- “재료마다 다른 패턴을 조심하라!”

## 10. GUI (원안 컨셉)

인게임 한 장의 구성. **체크리스트·말풍선·재료 트레이는 Unity 필수 아님.**

- 가운데: 피자 + 원판 + 하단 히트 + 노트 트레일
- 왼쪽: 주문 체크리스트 (반죽 → 토마토 소스 → 치즈 뿌리기 → 페퍼로니 → 오븐)
- 오른쪽: 재료 트레이
- 위: 손님 초상 + “페퍼로니 피자 한 판 주세요!”
- 판정 텍스트: PERFECT / GOOD / BAD / MISS
- 진행 바 / 정확도

Unity 최소 HUD: 현재 테마 이름, 정확도, 판정 팝업.

## 11. 작업 분담 · 에셋

노션 보드 기준. 완료 컬럼은 기획서 초안·영상 플로우·최종 기획서.

### 이서우 · 플밍

- 서브 기획
- Unity 재료 돌아가기, 트레일, 롱노트 원호 꼬리
- Unity 자동 판정 (Good과 Perfect 섞음)
- Unity 피자 오븐에 넣고 꺼내기 (원판·히트 라인 유지)
- Unity 상황에 따라 테마(배경) 변경
- 발표 PPT

타격 이펙트·재료가 피자에 붙는 연출은 영상 편집.

### 배성영 · 기획

- 최종 영상 편집 총괄
- 발표 PPT
- 그림 어시스턴트
- 재료 페퍼로니, 치즈

### 유승민 · 기획

- 발표 PPT
- Suno 노래 뽑기

### 김효은 · 아트

- 게임 로고, 팀 로고
- 여자 손님 걷기
- 피자 가게 외관, 테이블, 주문 받는 곳 화면
- 재료 도우·소스
- 화덕 이펙트
- 스테이지 클리어 장면
- 발표 PPT

### 박정민 · 아트

- 손님, 주방장 초상화
- 피자 원판
- UI 진행 테마, 현재 곡 정보, 정확도 스크롤, 메뉴 아이콘
- 반죽 / 소스 / 치즈 뿌리는 애니메이션
- 편집용 재료 떨어지기
- 발표 PPT

교체 가능한 아트가 오면 런타임 플레이스홀더(원·링·색면)를 바꾸면 된다.

## 12. 아직 열어 둔 것

아래는 숫자·세부만 비어 있다.

- 롱노트 꼬리 길이(박). 꼬리가 덮는 원호 길이는 여기서 나온다
- 치즈가 왼쪽으로 튕기는 거리·돌아오는 시간
- 페퍼로니가 다른 노트보다 얼마나 빠른지
- 재료별 노트 아이콘·색 값
- 노트 트레일 길이·두께·페이드
- Good과 Perfect를 섞는 비율 (섞는다는 것만 확정, 비율은 미정)
- Bad / Miss 감점 수치. 트레일러에는 안 나오지만 값은 채워야 한다

판정 윈도우 숫자는 기본값이며, 촬영 느낌 보고 바꿔도 된다.
