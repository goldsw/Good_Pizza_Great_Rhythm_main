# 작업지시 C-05 — 오븐 들어가기·나오기

담당: C (뷰와 연출)

A와 B는 하지 않는다. 채보의 `pizza` 값이 이미 순서를 말한다. 오븐 페이즈는 `IntoOven`(1), 완성 페이즈는 `OutOfOven`(2), 재료 페이즈는 `None`(0)이다. 페이즈 이름으로 분기하지 않는다.

고칠 곳은 `Assets/GPGR/View/PizzaOvenView.cs`뿐이다. 원판, 히트 마커, 노트 레일은 이 연출에 넣지 않는다. 배치 숫자는 `Docs/작업지시_C_04_배치.md`를 따른다. 집의 y는 -1.64, `OvenPoint`의 y는 2.54다.

---

## 1. 지금 구조가 막히는 이유

`PhaseEntered`가 오면 위치와 크기를 0.6초 동안 한 번에 보간한다. 페이드가 없고, 오븐이 아닌 페이즈는 전부 집으로 돌아간다. 그래서 재료 페이즈마다 나오는 연출이 다시 돈다.

이번 작업은 그 한 번의 보간을 단계로 나눈다. 한 단계가 끝난 뒤에만 다음 단계가 시작한다. 이동 중에는 알파를 바꾸지 않고, 페이드 중에는 위치를 바꾸지 않는다.

---

## 2. 자리 세 개

| 자리 | 위치 | 크기 | 알파 |
|---|---|---|---|
| 집 | 플레이 시작 때 잡아 둔 피자 위치 | 원래 스케일 | 1 |
| 입구 | 집에서 `OvenPoint`로 가는 길의 중간 | 집과 오븐 크기 사이 | 페이드가 일어나는 자리 |
| 안 | `OvenPoint` | 집 크기 × `ovenScale` | 0 |

입구 비율은 인스펙터에 둔다. 0이면 집, 1이면 오븐 점이다. 잠정 0.65. 입구용 오브젝트를 새로 만들지 않는다.

알파를 바꾸는 대상은 피자의 `SpriteRenderer`다. 원판 스프라이트는 건드리지 않는다.

---

## 3. 들어갈 때

오븐 페이즈(`IntoOven`)에서만 재생한다.

1. **이동.** 집 → 입구. 알파는 1로 유지한다.
2. **페이드아웃.** 입구에 멈춘 채로 알파를 0으로 내린다. 이 단계가 끝나기 전에 안으로 들어가지 않는다.
3. **들어가기.** 투명한 채로 입구 → 안. 크기는 오븐 크기로 줄인다.

---

## 4. 나올 때

완성 페이즈(`OutOfOven`)에서만 재생한다.

1. **나오기.** 안 → 입구. 알파는 0으로 유지한다. 크기는 입구 크기로 돌아온다.
2. **페이드인.** 입구에 멈춘 채로 알파를 1로 올린다.
3. **이동.** 입구 → 집. 크기는 원래 스케일로 돌아온다.

나올 때의 이동은 페이드인이 끝난 뒤에 시작한다.

---

## 5. 재료 페이즈

`None`이면 이 순서를 재생하지 않는다. 피자는 집에 있고 알파는 1이다.

차트 재생이 처음부터 다시 시작되면, 진행 중이던 단계를 끊고 집·알파 1·원래 크기로 즉시 되돌린다. 페이드가 남은 채로 반죽이 시작되면 안 된다.

이미 같은 방향으로 연출이 끝나 있으면 같은 페이즈가 다시 들어와도 단계를 반복하지 않는다. 오븐 롱노트 도중 피자가 입구와 안을 왕복하지 않게 한다.

---

## 6. 시간

단계마다 초를 인스펙터에 둔다. 코드에 한 값으로 박지 않는다.

| 단계 | 잠정 |
|---|---|
| 집 → 입구 | 0.45초 |
| 페이드아웃 | 0.2초 |
| 입구 → 안 | 0.2초 |
| 안 → 입구 | 0.2초 |
| 페이드인 | 0.2초 |
| 입구 → 집 | 0.45초 |

이동은 `SmoothStep`으로 잇는다. 페이드는 선형으로 한다.

---

## 7. 확인

`editor_play`로 오븐 페이즈와 완성 페이즈를 본다.

| 볼 것 | 맞는 모습 |
|---|---|
| 들어가기 | 오븐 쪽으로 움직인 뒤, 앞에서 사라진 다음, 안으로 들어간다 |
| 오븐 도중 | 피자는 안쪽에 머문다. 원판과 히트 마커는 제자리다 |
| 나오기 | 오븐 앞에서 나타난 뒤, 페이드가 끝나고 나서 집으로 이동한다 |
| 재료 페이즈 | 피자가 집을 떠나지 않는다 |
| 다시 재생 | 피자가 보이고, 집 위치에 있다 |

---

## 8. 끝나고 보고할 것

1. `None` 페이즈에서 나오는 연출이 재생되지 않는지
2. 페이드와 이동이 겹치는 프레임이 있는지
3. 단계별 인스펙터 초
4. 스크린샷 또는 들어갈 때·나올 때 각 한 장
