## 1. 임포트

Texture Type은 Sprite (2D and UI). Alpha Is Transparency를 켠다. Mesh Type은 Tight가 아니라 Full Rect로 둔다. `Pizza_CD`는 오른쪽에 빈 픽셀이 많아서, Tight로 자르면 중심이 어긋난다.

피벗:

| 스프라이트 | 피벗 |
|---|---|
| `WheelBoard` | 원판 나무 원의 중심. 스프라이트 정중앙이 아니다. 손잡이가 아래로 길게 있다 |
| `Pizza` | 피자 그림의 중심. 텍스처 정중앙이 아니다. 피자는 왼쪽에 치우쳐 있다 |
| 노트 4개, `BgDark` | Center |

Pixels Per Unit은 노트끼리 같게 둔다. 원판 위에서 아이콘이 서로 비슷하게 보여야 한다. 숫자를 코드에 새로 박지 말고, 씬에서 트랜스폼 스케일로 크기를 맞춘다.

복사한 뒤 `unity command import_asset`으로 임포트한다. `.meta`는 내가 만든 파일의 것만 생긴다. A가 나중에 이 경로로 스프라이트를 찾으므로 파일 이름을 바꾸지 않는다.

## 2. 씬에 꽂기

`Trailer.unity`만 고친다. 코드로 한다. `TrailerEditor`에 메뉴를 하나 더 두거나, 기존 `GPGR/View/Add Runtime Components` 옆에 `GPGR/View/Apply Ingame Art`를 만든다. 인스펙터에서 스프라이트를 끌어 넣고 끝내지 않는다.

| 씬 대상 | 스프라이트 |
|---|---|
| 원판 링 (`Wheel` / `Ring`) | `WheelBoard` |
| 피자 (`PizzaRig/Pizza`) | `Pizza` |
| 어두운 배경 (`Backgrounds/Dark`) | `BgDark` |
| 밝은 배경 | C-03에서 `Pizza_Store3`로 바꾼다. 여기서는 건드리지 않는다 |
| 히트 마커 | 그대로. 원본에 히트 라인 그림이 없다 |

원판은 회전하지 않는다. 손잡이가 화면 아래(270°)로 가게 둔다. 히트 마커는 나무 원의 가장자리, 손잡이 시작점 근처에 둔다. 손잡이 한가운데로 들어가면 마커가 사라지니, 원 위로 살짝 올린다.

피자 그림의 부모는 원판이 아니다. 오븐 페이즈에서 피자만 작아지며 들어가고, 링과 히트 마커는 그 자리에 남는다. `PizzaOvenView`의 `ovenScale`, `moveSeconds`는 인스펙터 값이다. 그림이 너무 크거나 작으면 그 값만 조정한다.

`flameAnchor`는 비워 둔다. 불꽃으로 쓸 스프라이트가 없다.

배경은 여전히 밝음/어두움 두 장이다. 페이즈 이름으로 그림을 고르지 않는다. `Dark_Effect`는 어두운 갈색 면이라 오븐 페이즈의 `backdrop == Dark`에 맞다.

## 3. 노트 프리팹

`Note.prefab`의 아이콘 `SpriteRenderer`는 비워 둔다. 실제 그림은 런타임에 `NoteRow.icon`에서 온다. 프리팹에 치즈를 박아 두면 모든 노트가 치즈로 보인다.

아이콘은 궤도를 따라 이동하고 회전하지 않는다. 피벗이 Center면 그대로 두면 된다.

## 4. 확인

`editor_play`로 트레일러를 켠다. `capture_game_view --source screen`으로 남긴다.

| 볼 것 | 맞는 모습 |
|---|---|
| 원판 | 나무 도마가 가운데 있고, 손잡이는 아래를 향한다 |
| 히트 | 하단 마커가 도마 원 위에 보인다 |
| 피자 | 도마 중심에 피자가 있다. 왼쪽으로 치우쳐 있으면 피벗이 틀렸다 |
| 오븐 페이즈 | 배경만 어두운 갈색이 되고, 피자가 작아지며 들어간다. 도마와 히트 마커는 안 움직인다 |
| 완성 | 배경이 다시 밝아지고 피자가 나온다 |
| 노트 | 아이콘이 비어 있거나 예전 원으로 보여도 된다. A가 채보에 꽂기 전이다 |
