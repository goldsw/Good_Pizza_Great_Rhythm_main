# 작업지시 C-03 — 배경, 검은 길, 스폰·타격 이펙트

담당: C (뷰와 연출)

A와 B에게 나누지 않는다. `Docs/Unity_구조.md`에서 배경, 원판 위의 보이는 것, 트레일은 인게임 연출이다. 파티클도 그 연출이다. 판정과 박자 계산은 이미 `NoteWheel`에 있다.

| 이벤트 | 있는 곳 | 의미 |
|---|---|---|
| `NoteWheel.Spawned` | `Assets/GPGR/Runtime/NoteWheel.cs` | 노트가 처음 나옴 |
| `NoteWheel.Judged` | 같은 파일 | 그 노트를 판정함 |

이 둘을 구독한다. 런타임 어셈블리에 이벤트를 추가하지 않는다. `Assets/GPGR/Charting/`, `Assets/GPGR/Runtime/`, `Assets/GPGR/EditorTools/`, `Assets/GPGR/Charts/`는 읽기만 한다.

상시 규칙은 `지침_C_뷰와_연출.md`다. 노트 아이콘 파일은 `Docs/작업지시_C_02_인게임아트.md`대로 두고, 이 문서의 그림은 배경이다.

파티클로 깔지 않는다. 검은 원에서 가운데를 빼 고리로 만든다. 절차는 `Docs/작업지시_C_06_레일.md`다.

## 2. 스폰 이펙트와 타격 이펙트

둘 다 `ParticleSystem`이다. 노트 프리팹에 상시로 켜 두지 않는다. 필요할 때 그 위치에서 한 번 터뜨리고, 파티클은 월드 좌표로 남아 노트를 따라가지 않는다.

| 언제 | 이벤트 | 위치 |
|---|---|---|
| 처음 스폰 | `NoteWheel.Spawned` | 그 노트의 현재 각도. `MotionPath.Position` |
| 쳤을 때 | `NoteWheel.Judged`이고 판정이 Miss가 아닐 때 | 같은 방식 |

Miss는 치지 못한 것이다. 타격 이펙트를 내지 않는다. 빈 입력도 이벤트가 없으니 이펙트가 없다.

스폰과 타격은 서로 구분되게 만든다. 스폰은 짧게 퍼지는 링, 타격은 한 점의 폭발처럼 보이게 하면 된다. 색은 그 행의 `NoteRow.color`를 쓴다. 재료 이름으로 분기하지 않는다.

판정 텍스트는 지금 HUD가 한다. 파티클이 HUD 글자를 대신하지 않는다.
